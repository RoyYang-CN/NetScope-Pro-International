1What NetScope does

NetScope Pro is a wireless network engineering and capacity-planning assistant. It uses engineering parameters and PRB load data to identify high-load, load-balancing, hardware-expansion and low-load-reduction candidates.

Geospatial matching

Uses WGS-84 geodesic distance, azimuth and coverage type to identify co-site, same-coverage and opposite candidates.

Load analysis

Counts valid PRB records for high-load, low-load and balancing conditions.

Engineering outputs

Produces candidate tables, decisions, audit workbooks and an HTML management report.

2Registration and licensing

New users receive a 12-natural-day full Trial with unrestricted input and detailed output.
2
Enter a license key
Open Registration, enter the License Key and click Activate Now. A successful activation immediately switches the current window to full licensed mode.
3
Free mode
After Trial expiry without a valid license, the complete network analysis still runs. Public detailed tables export the first 100 rows, while summary totals remain complete.
4
Pro mode
A valid annual license enables full detailed output. When it expires, the application returns to Free; renewal or reactivation restores full output.
Important: Licensing does not change Step 1–4 input rules, candidate algorithms or decision logic. Free mode limits only the final public detail output, not the analysis input size.

The purchase link is available through the Buy License button in Registration. Activation requires network access; engineering data processing is local.

4.2 Performance fields

Long format

One row per cell per day: Cell Name, ENBID, CELLID, StartTime and PRB_Load.

Wide format

One row per cell, followed by date columns containing daily PRB load values.

PRB load: Supports values such as 0.7 and 70%. UI ratio input supports ratio / percent / auto; 70% is normalized to 0.7.
Do not use: negative PRB, percent values over 100, unrecognized bandwidth, zero/negative bandwidth, invalid coordinates or zero as a substitute for an anomaly.

5Import and start analysis

1
Open the application and go to Run Analysis.
2
Select Network_Cell_Info.xlsx or CSV as the engineering file.
3
Select the PRB performance Excel/CSV file. Long and wide formats are supported.
4
Review the parameters and click Start Analysis. Do not move or edit input files during execution.
5
When complete, click Open Results Folder to inspect CSV files, the HTML report, run status and audit workbook.
Multi-sheet Excel: Use exported templates whenever possible. Keep instructions separate from the data sheet and put the true header on row 1; ambiguous target sheets are reported as errors.

6Configure parameters

Thresholds

High-Load Cell Threshold, High-Load Valid Days and FDD/TDD/3D-MIMO thresholds.

Low load and balancing

Low-Load Cell Threshold, Reduction Merge Safety Threshold, load-balance start difference, target safety threshold and effective difference.

Lists and filters

Low-load blacklist frequencies restrict cells used as reduction candidates; high-load and expansion lists retain their separate meanings.

Geometry and distance

Opposite search radius, same-site distance, minimum opposite distance, sector tolerance, forward half-angle and maximum candidates per source cell.

Tooltips: Hover over the ⓘ beside a parameter to view its bilingual explanation. Start with defaults on a sanitized dataset before tuning project-specific thresholds.

7Step 1–4 workflow

1
Step 1 · Data Prep
Reads Excel/CSV, identifies headers, normalizes bandwidth and PRB, creates cell_uid and audits coordinates, duplicates, performance and input formats.
2
Step 2 · Candidate Finding
Generates candidates using high-load, geometry, azimuth, indoor SN and load rules. Internal candidates are kept in a hidden folder; the public table contains user-facing fields. If indoor SN is empty or missing, same-site distance and azimuth matching can be used as a fallback.
3
Step 3 · Decisions
Reviews expansion, balancing and reduction decisions. Low-load reduction uses the bandwidth-adjusted merged-load safety threshold.
4
Step 4 · Final Report
Generates the HTML report, frequency distributions, balancing details, hardware-expansion details, reduction details and anomaly summary.

Reduction direction and bandwidth formula

src is the retained cell that carries the load; cand is the cell being evaluated for reduction. Every record is shown as src → cand.

weighted_merge_load = src_prb + cand_prb × (cand_bandwidth / src_bandwidth)

Example: src = 14.4% / 20 MHz and cand = 46.33% / 100 MHz gives 246.05%. If the safety threshold is 60%, no reduction recommendation is generated for cand.

For SN matching, distance_m = 0 means logical co-location, not a measured physical distance.

9Read the results

High-load governance

Review same-coverage and opposite balancing candidates first. If no suitable target exists, the source may receive a hardware-expansion recommendation.

Load balancing

The report shows strong same-coverage balancing before strong opposite balancing; geometry, load and safety checks all apply.

Hardware expansion

Review in descending source maximum PRB order, then verify expansion_freq against engineering constraints.

Low-load reduction

Review in ascending bandwidth-adjusted merged load order; cand is the potential reduction target and must be manually reviewed.

Engineering boundary: Results are capacity and geometry candidates, not final coverage, interference, transport, power or construction conclusions. Engineers must review recommendations against the live network and site conditions.

10Data quality and anomalies

Invalid coordinates, PRB anomalies, invalid bandwidth and conflicting duplicate keys are not silently converted to zero. They are audited and either excluded or block the affected analysis according to the issue type.

Input failure

Header, sheet, date or required-field errors stop the run with a clear message.

Input warning

When some records are invalid, valid records may continue while anomaly counts are written to the audit workbook.

No candidates

The workflow completed normally, but the current data and parameters produced no candidate to display.

11Frequently asked questions

Why do I see “Perf table missing Cell Name column”?

The performance table has no recognizable cell-name field, or the real header is not on row 1. Use the long/wide template and keep the data header on the first row.

Why can’t a multi-sheet workbook be imported?

The target sheet cannot be identified uniquely. Use the exported template or configure the target sheet explicitly; keep instructions outside the data table.

Can I mix 70% and 0.7?

Load values support 70% and normalize it to 0.7. 0.7 is a ratio. Do not enter a unitless value greater than 1 and expect the program to guess its meaning.

Does Free mode analyze only 100 rows?

No. Free mode runs the complete input analysis. Only public detailed tables are limited to the first 100 rows; summary totals remain complete.

Why is distance equal to zero?

For an SN logical match, distance_m=0 means logical co-location, not a measured physical distance.

What should I do if Windows SmartScreen blocks the EXE?

This can occur when a standalone EXE is not signed with a commercial code-signing certificate. Verify the source and SHA-256, then choose More info → Run anyway if appropriate.

12Usage boundary and support

Input contract: The International Edition currently supports WGS-84 longitude/latitude in degrees only. Do not import projected coordinates, another CRS or undocumented coordinate units.

Keep the input files, configuration, run_manifest.json, run_status.json and the data-quality audit workbook for later review.
